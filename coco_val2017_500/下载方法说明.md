## 三、下载过程中踩到的坑（重点）

### 1. HTTPS 用不了，必须用 HTTP
官方 CDN 对 `https://images.cocodataset.org` 返回的证书与该域名不匹配
（`CERTIFICATE_VERIFY_FAILED / SEC_E_WRONG_PRINCIPAL`），**换梯子、换 DNS 都一样**——
这是官方服务器本身的证书配置问题，不是网络干扰。因此全部走明文 HTTP 下载。

### 2. 单连接被限速，且很不稳定
实测单连接速度约 **19~87 KB/s** 波动。直接下 241 MB 的 zip 要 1 小时以上，不可行。

### 3. 并行 Range 分段下载 = 破局关键
服务器支持 HTTP `Range` 请求（响应 `206`）。用多线程分段拉取同一个大文件，
实测 **8 连接聚合速率约 413 KB/s**，241 MB 的 zip 约 8 分钟下完。

### 4. 命令行进程默认不走梯子
Windows 系统代理（WinINET）开了梯子（`127.0.0.1:10090`），但 python/curl 默认不读它，
出口 IP 仍是国内（如 221.239.73.66）。需要显式给下载脚本挂代理：
`ProxyHandler({'http': 'http://127.0.0.1:10090', 'https': 'http://127.0.0.1:10090'})`

## 四、下载步骤（可复现）

### 第 1 步：并行下载标注包并解出 instances_val2017.json
```bash
python E:\Simulator\coco_val2017_500\download_zip_parallel.py
```
脚本逻辑：
1. 把 252,907,541 B 分成 **12 段**，每段约 21 MB；
2. 12 线程并发，带 `Range: bytes=start-end` 请求（走代理 `127.0.0.1:10090`），每段最多重试 6 次；
3. 全部成功后按顺序拼接成完整 zip，用 `zipfile` 校验并只解出 `annotations/instances_val2017.json`。

### 第 2 步：选 500 张 + 并行下载图片 + 生成子集标注
```bash
python E:\Simulator\coco_val2017_500\prepare_coco.py
```
脚本逻辑：
1. 从 `instances_val2017.json` 的 5000 张图中，用**固定随机种子 `seed=42`** 抽 500 张（结果可复现）；
2. **16 线程**并发下载每张图片（HTTP + 代理），校验 JPEG 魔数（`FF D8 FF`），失败自动重试；
3. 过滤标注：只保留这 500 张图对应的 `annotations`，写出 `instances_val2017_sub500.json`；
4. 生成绝对路径清单 `val2017_sub500.txt`（供 YOLO/ultralytics val 使用）。

### 第 3 步：完整性校验
```bash
python E:\Simulator\coco_val2017_500\verify_subset.py
```
校验项：图片数量、0 字节/坏 JPEG、JSON 结构、JSON↔磁盘双向覆盖、标注条数、txt 路径有效性。

## 六、参数怎么改（自定义）

- **张数**：改 `prepare_coco.py` 里的 `N_SELECT = 500`；
- **选图方式**：改 `SEED = 42`（换种子换一批图）；也可以把 `rng.sample(...)` 换成按 ID 顺序取前 N 张；
- **代理**：改两个脚本里的 `PROXY = 'http://127.0.0.1:10090'`（换成自己梯子的本地端口，比如 Clash 常为 7890、v2rayN 常为 10809）；不开梯子可改成 `None` 并删掉 `ProxyHandler`；
- **下载线程数**：改 `WORKERS = 16`（图片）、`CHUNKS = 12`（zip 分段数）。

## 七、注意事项

1. 以上下载全部来自 COCO 官方源（`images.cocodataset.org`），走明文 HTTP；
2. 若后续要 YOLO 格式的 txt 标注（`class cx cy w h`），可用 ultralytics 的
   `yolo2coco`/`coco2yolo` 或官方 `cocoapi` 把 `instances_val2017_sub500.json` 转换，需要的话随时说；
3. 如需完整 5000 张 val2017，把 `N_SELECT` 改成 5000 即可（或直接下 `val2017.zip`）。
