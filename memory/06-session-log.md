## 二、已确认的结论

### 2.1 核心事实

1. **INT8 全量化会把 YOLOv8n 打崩**：494 张图 **0 个检测**，mAP@0.5 = 0.0000
   （float 基准 0.4332）。
2. **根因是输出张量范围冲突**：`output0` 形状 `(1,84,8400)`，把框坐标（0~640）
   与类别概率（0~1）混在同一 int8 张量，一个 `scale` 覆盖不了相差 3 个数量级的范围，
   概率被量化步长抹成 0。实测 **672000 个类别分数全为精确的 0.0**，而框回归支路正常。
3. **故障指纹**：*框回归正常 + 类别分数全 0*。
4. **修复**：把 `output0-rs`、`output0_int8` **两层**设为非量化 →
   mAP@0.5 = **0.4387**，模型 4.82 → **4.89 MB**，主干保持 int8。

### 2.2 被推翻的中间结论（重要）

| 曾经的结论 | 现状 |
| :--- | :--- |
| "敏感层在检测头 `cv3.*`，保检测头即可" | ❌ **错**。保整个检测头 51 层仍为 0 检测 |
| "真正决定成败的是主干（132 层）" | ❌ **错归因**。那只是假象，见 §三 |
| "切尾巴是最优解" | ⚠️ **降级为备选**。仅保输出层改动更小、效果相同 |

### 2.3 待验证（弱证据）

**"换校准集无效"** 仅基于 **5 张图**、只比"检测数是否为 0"，
**未在全量算 mAP**。机理推断合理，但属**弱证据**。

## 三、关键陷阱：为什么"保主干有效"是假象

按 `/model.` 前缀筛层时，**`output0-rs` 与 `output0_int8` 不带该前缀**，
于是被"主干"集合**顺带纳入**了——所以"保主干"看起来有效，
实际起作用的只是那 2 个输出层。**决定性证据**：

| 试验 | 设为非量化 | 层数 | 检测数 |
| :--- | :--- | :--- | :--- |
| T1 | 仅 `output0-rs` + `output0_int8` | 2 | **112** ✅ |
| T2 | 主干（**不含**输出） | 130 | 0 ❌ |
| T3 | 主干 + 输出 | 132 | 104 ✅ |
| T4 | 主干前半 | 78 | 0 ❌ |
| T5 | 主干前半 + 输出 | 80 | 105 ✅ |

**T2 vs T3 只差 2 个输出层，结果从 0 变 104。**

> **教训**：按名字前缀筛层是危险的——会悄悄改变实验的变量。
> 用消融实验验证，不要相信"看起来合理的归因"。
