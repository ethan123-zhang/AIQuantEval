## 🔴 P1 — 阻塞对外结论

### 1. 校准集与评估集同源（**风险最高**）

- 校准集 `calib_images/` = val2017 的 500 张。
- 评估集 `precision_analysis/data/images` = **同一批** val2017 的 494 张。
- 违反项目 README 自己强调的「**校准集和测试集必须分开**」。

**影响**：`0.4387` 这个数字**有虚高风险，不可对外引用**。纯 INT8 的 0.0000 不受影响。

**要做什么**：从 val2017 里挑一批**未参与校准**的图做评估集重测。
（注意：需重新跑 `prepare_coco.py` 生成对应标注。）
